# execlab

A networked historical execution laboratory, written in OCaml in the
Jane Street style ([`Core`](https://opam.ocaml.org/packages/core/),
`ppx_jane`, `dune`, expect tests).

Users upload the trade instructions generated by an alpha strategy, run
them through configurable TWAP, VWAP, POV, implementation-shortfall,
or adaptive
execution algorithms in a market calibrated to historical stock data,
and measure how much theoretical alpha survives realistic execution
costs.

See **`context.md`** for the full project plan, design decisions, and
current progress, and **`CLAUDE.md`** for code conventions.

## Build, test, format

```sh
dune build                      # compile
dune runtest                    # run tests
dune fmt --auto-promote         # format (.ocamlformat: janestreet profile)
dune exec bin/main.exe -- 150.25   # run the example binary
```

The generated `execlab.opam` is produced by dune from `dune-project` —
don't edit it by hand; it regenerates on the next `dune build`.

## Layout

```
lib/types/    core domain types (Execlab_types: Price, Side, Size,
              Symbol, Order_id, Level, Bbo, Liquidity, Fill, ...)
lib/alpha/    alpha-output CSV parser (in progress)
bin/main.ml   example executable
```

## GitHub Actions

- **`.github/workflows/ci.yml`** — builds, tests, and checks formatting
  on every push to `main` and every PR.
- **`.github/workflows/claude.yml`** — runs the
  [Claude Code Action](https://github.com/anthropics/claude-code-action)
  when someone writes `@claude` in an issue or PR (needs an
  `ANTHROPIC_API_KEY` or `CLAUDE_CODE_OAUTH_TOKEN` secret).
